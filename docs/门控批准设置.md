# 门控批准设置

## 为什么会直接退出

当前的启动姿势（没带 `--mode` 也没在配置里启用 `hitl:`）会走到这条分支 —— `researchclaw/cli.py:190-192`：

```python
else:
    # "semi-auto" and "docs-first" should block on gates
    stop_on_gate = True
```

此时 `hitl_config` 是 `None`，也就**没有任何 HITL 适配器被挂上**（`cli.py:328` 的 `if hitl_config and hitl_config.enabled:` 条件不满足，`CLIAdapter` 不会被注册）。

于是当管道跑到第 5 / 9 / 20 号门控阶段时：

1. `executor.py:749-761` 把该阶段标成 `BLOCKED_APPROVAL`，只发一条通知；**不会调用 `input()` 弹出交互**。
2. `runner.py:628` 只打印一行 `… — blocked (awaiting approval)` 就返回。
3. `runner.py:805` 看到 `stop_on_gate=True` 直接 `break`，管道退出。

你看到的正是：打印一行就没了，无处可输入，进程结束。

---

## 怎么改成「能看见提示、按键批准、连续跑完」

最直接的就是启用 HITL 交互模式 —— **加 `--mode`**。这会走 `cli.py:329-354`，把 `CLIAdapter.collect_input()` 挂到 session 上，在同一个进程里用 `input(...)` 阻塞等键（`cli_adapter.py:113`），你会看到一个带横线分隔、标题、上下文摘要、可选动作（`approve / reject / edit / collaborate / skip / rollback / abort / view`）的面板，按键后继续往下跑，**不退出**。

### 方案 A（推荐，零改动）— 每次运行加 `--mode`

```bash
researchclaw run --topic "..." --mode gate-only
# 或
researchclaw run --topic "..." --mode co-pilot
```

各 preset 的差别（`researchclaw/hitl/presets.py`）：

| `--mode` | 暂停频率 | 适用场景 |
|---|---|---|
| `gate-only` | 仅 Stage 5 / 9 / 20 | 最接近「默认 3 个门控」，想一次性批准 |
| `express` | Stage 8 / 9 / 20 | 经验用户，干扰更少 |
| `co-pilot` | 关键阶段深度协作 | 平衡质量与效率（默认推荐） |
| `thorough` | 每个 phase 边界 | 对质量要求高 |
| `step-by-step` | 每个阶段都停 | 学习 / 调试 |
| `autonomous` / `full-auto` | 不停 | 等同 `--auto-approve` |

> 注意：resume 时 `--mode` 要**再带一次**，`--mode` 不会写进 checkpoint。

### 方案 B — 在配置文件里永久启用

编辑 `config.arc.yaml`，加一段：

```yaml
hitl:
  enabled: true
  mode: "gate-only"        # 或 co-pilot / express / thorough
  timeouts:
    default_human_timeout_sec: 86400
    auto_proceed_on_timeout: false
```

这样就不用每次加 `--mode`。`cli.py:276-281` 会识别并自动把 `stop_on_gate` 关掉，gates 由 HITL 会话直接处理。

### 方案 C — 完全不要停

`--auto-approve` 或 `project.mode: full-auto`：gates 全部自动通过（`cli.py:184-189`），但这样就不需要你来批了。

## 如果真的已经退出了，怎么接着跑？

无需从头重跑：

```bash
researchclaw run --resume --mode gate-only
# 或显式指定输出目录
researchclaw run --output artifacts/rc-<id> --resume --mode gate-only
```

`--resume` 会从 `checkpoint.json` 读取最后 DONE 的阶段接着跑（`cli.py:301-305`）。如果没带 `--output`，`cli.py:220-237` 会根据 topic hash 在 `artifacts/` 里自动找最近一次运行目录。

## 交互面板里的按键

进入 HITL 面板后可用键（`cli_adapter.py:75-96`）：

| 键 | 动作 |
|---|---|
| `a` | approve — 批准，继续下一阶段 |
| `r` | reject — 驳回，触发回滚 |
| `e` | edit — 编辑当前阶段输出 |
| `c` | collaborate — 进入多轮对话协作 |
| `i` | inject — 注入额外上下文 |
| `s` | skip — 跳过非关键阶段 |
| `b` | rollback — 回到前一阶段 |
| `q` | abort — 终止整条管道 |
| `v` | view — 查看完整输出（不退出面板） |

按回车前可以反复 `v` 查看完整输出再决定。
